# 🏥 Featured Project

## ASHA / Nurse Family Management System

A Django-based web application designed around a real-world healthcare workflow for managing families and their members.

### 🔐 Login

- 6-Digit PIN authentication
- Admin-managed PIN

### 📊 Dashboard

- Family overview
- Member overview
- Simple and clean interface

### 👨‍👩‍👧 Family Management

- Add Family
- Family Details
- Family List
- Search Families
- View Family Members

### 👤 Member Management

- Add Member
- Name
- Age
- Gender
- Relation
- Search Members
- View Member
- Edit Member
